# SheepShaver (WebAssembly)

This directory contains the PowerPC emulator core for the macintosh.js PPC
variant.

## Provenance

`SheepShaver.js` and `SheepShaver.wasm` are the unmodified Emscripten build from
Infinite Mac (https://github.com/mihaip/infinite-mac, Apache License 2.0),
vendored at commit `edc74a11b39777bbc2748cdb00730faf2adce670`. That build
descends from SheepShaver by Christian Bauer et al. (GPLv2, see `LICENSE.txt`).

`rom.bin` is a user-supplied New World PowerPC ROM. It is not part of the
Infinite Mac build and is subject to Apple's copyright.

## Layout

- `SheepShaver-worker-boot.js` — core-specific worker entry; shared glue is in
  `src/renderer/emulator-worker-boot.js`.
- `prefs_template` — SheepShaver preferences. The screen size and disk list are
  appended by the worker at startup.
- `disk` — assembled Mac OS 8.6 boot image (generated by
  `npm run disk:assemble:ppc`, not checked in).
